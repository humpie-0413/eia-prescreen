## 4. 발견된 이슈

### 4.1 유사사례 라이브러리 미보유 유형
- **mining** (채석·광업): 89건 사례 라이브러리에 mining 유형 0건 → 유사사례 검색 결과 0건
- **forest** (산지개발): 89건 사례 라이브러리에 forest/mountain 유형 0건 → 유사사례 검색 결과 0건
- **개선 권장**: 두 유형에 대해 최소 3~5건의 큐레이션 사례 추가 필요

### 4.2 기타(other) 유형 유사도 매우 낮음
- other 유형 유사사례 유사도: 0.070~0.076 (타 유형 0.33~0.36 대비 1/5 수준)
- **원인**: other는 범용 유형으로 사례 특성이 분산, 코사인 유사도 자연히 낮음
- **개선 권장**: other를 세분화하거나, 유사도 임계값 로직 추가 검토

### 4.3 매립(reclamation) 유사사례 희소
- reclamation 유형: 1건만 반환
- **개선 권장**: 매립·간척 사례 추가 큐레이션

### 4.4 규제 매칭 편차
- 최소 1건 (15-1 군산 비응도) ~ 최대 19건 (14-1 낙동강 하구, 17-2 부산 북항)
- 군산 비응도의 1건은 매립 특화 규제만 매칭 — 해양환경관리법 등 추가 매핑 검토

### 4.5 LLM 해석문 미생성 (일부 사례)
- Gemini 2.5 Flash 호출 성공하나, 일부 사례에서 해석문 길이 0 반환
- DEMO_MODE=true에서 LLM 호출 타이밍 이슈 가능성
- **영향**: 리스크 해석문 없이도 카드형 규칙 출력은 정상 동작

### 4.6 커넥터 가용성 (위치 기반 정상 편차)
- 내륙 사례: ocean 커넥터 미가용 (50km 이내 관측소 없음) — 정상
- 도서 지역 (백령도): hydrology + ocean 미가용 — 정상
- 이는 설계 의도대로 graceful 빈 데이터 반환
