## 수집 완료 후 Claude Code에 전달하는 방법

### 유사사례 (D-1 완료 후)
수집한 텍스트를 `raw_cases.txt`로 저장한 후:
```
raw_cases.txt를 읽고 data/cases/cases.json의 기존 50건을 교체해줘.
태깅 스키마는 기존과 동일. key_issues, tags는 내용 기반으로 자동 생성.
case_search.py 테스트도 돌려줘.
```

### 데모 부지 (D-4 완료 후)
확인한 부지 정보를 Claude Code에 직접 전달:
```
데모 시나리오 3개의 mock 데이터를 실제 데이터로 교체해줘:
양평: 좌표 (37.XXXX, 127.XXXX), 용도지역 OO, 규제 OO...
세종: 좌표 (36.XXXX, 127.XXXX), 용도지역 OO...
보령: 좌표 (36.XXXX, 126.XXXX), 용도지역 OO...
리스크 엔진 재실행해서 결과도 업데이트해줘.
```
