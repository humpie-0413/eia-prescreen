# EIA Pre-Screen — Product Scope

## 제품 한 줄 정의

사업 위치와 유형을 입력하면 공식·캐시 데이터와 사례 라이브러리를 바탕으로 환경영향평가 초기 단계의 입지 리스크와 우선 검토 항목을 근거와 함께 제시하는 사전검토 지원 도구.

## 이 도구가 답하려는 질문

> "이 부지는 무엇이 위험하고, 어떤 규제가 걸리며, 무엇부터 조사해야 하고, 유사사업에서는 어떤 이슈가 반복됐는가?"

## 제품 경계

### ✅ 하는 것 (In Scope)
1. 입지 리스크 스크리닝 (카드형, 설명 가능)
2. 법적 규제·인허가 자동 매칭
3. 평가항목 우선순위 추천
4. 유사사례 검색 (50건 큐레이션)
5. 다중 부지 비교 (최대 3개)
6. 현장조사 체크리스트 자동 생성
7. 데이터 가용성 대시보드
8. LLM 리스크 종합 해석문 (참고용 명시)
9. 1p 브리프 + 5~10p 환경현황 요약 보고서 PDF

### ❌ 하지 않는 것 (Non-Goals)
| 항목 | 이유 |
|------|------|
| 법적 판정 자동화 | 참고용 도구이며 법적 효력 없음 |
| 평가서 전체 자동 작성 | "사전검토 도구"의 범위를 벗어남 |
| HWP 직접 출력 | HWP 포맷 리버스 엔지니어링 필요, 후속 확장 |
| AERMOD 연계 자동화 | 전문 모델링 영역, 별도 프로젝트 급 |
| 주민의견/공람 workflow | EIASS 자체 기능과 중복 |
| 원문 전체 NLP 자동 분석 | 품질 보장 불가, LLM 보조 태깅이 대안 |
| 현장조사·전문 모델링 대체 | 현장 확인은 반드시 사람이 수행 |

## 주 사용자

**환경영향평가 대행사 주니어 실무자**

### 사용 시점
- 수주 검토 — 사업 수주 여부 판단 시
- 부지 후보 비교 — 복수 부지 간 리스크 비교 시
- 평가준비서/초기 검토 이전 — 본격 조사 전 방향 설정 시

## 핵심 원칙

1. **Evidence First** — 모든 결과에 근거(데이터 출처, 기준일자, 관련 법령)를 붙인다
2. **Unsupported Claim 금지** — 근거 없는 판단을 제시하지 않는다
3. **법적 효력 없음 명시** — 모든 결과는 참고용이며 법적·행정적 효력이 없음을 표시한다
4. **설명 가능성** — black-box 점수 대신 룰 기반 카드로 "왜 이 판단인지" 설명
5. **데이터 투명성** — 데이터 신선도, 캐시 전환 여부를 사용자에게 공개
