### 3.4 유사사례 50건 수동 수집

**이것이 가장 시간이 많이 드는 수동 작업입니다.**

#### 수집 절차

**Step 1. EIASS 접속 → 평가정보조회 → 사업조회**
- URL: https://www.eiass.go.kr/biz/base/info/searchListNew.do
- 평가구분: "환경영향평가" 선택
- 사업유형별로 검색 (도로, 산업단지, 발전소 등)

**Step 2. 사업 목록에서 50건 선정**
- 최근 5년 (2020~2025) 우선
- 협의완료 상태인 것만
- 사업유형별 분배 기준에 맞게

**Step 3. 각 사업 클릭 → 아래 정보 복사**

```
[협의결과]: 동의 / 조건부동의 / 보완 후 재협의
[주요 지적사항]: _____________
[보완 요구사항]: _____________
[협의 조건]: _________________
```

**Step 4. 수집한 내용을 텍스트 파일로 정리**
- 파일명: `raw_cases.txt`

### 3.5 데모 시나리오 실제 부지 확인
