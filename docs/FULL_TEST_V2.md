각 사례별로 다음 API를 호출:
1. POST /api/screening — 스크리닝 생성

4. GET /api/screening/{id}/cases — 유사사례
5. POST /api/screening/{id}/predict-review — 검토의견
6. GET /api/patterns/{type} — 패턴
