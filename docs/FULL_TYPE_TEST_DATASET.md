## 자동 테스트 스크립트용 JSON

Claude Code에서 전체 테스트를 실행하려면:

```
이 데이터셋으로 17개 사업유형 × 3개 = 51건 전체를 자동 테스트하는 스크립트를 작성하고 실행해줘.

backend/scripts/full_type_test.py:
1. 위 51건 데이터를 순차적으로 POST /api/screening
2. 각 사례에 대해 다음 API 호출:
   - GET /api/screening/{id}/evaluate (리스크)
   - GET /api/screening/{id}/regulations (규제)
   - GET /api/screening/{id}/cases (유사사례)
   - POST /api/screening/{id}/predict-review (검토의견)
   - GET /api/patterns/{type} (패턴)
3. 각 사례의 결과를 검증:
   - 리스크 카드 1건 이상
   - 규제 매칭 1건 이상
   - 검토의견 예측 1건 이상
   - 패턴 데이터 존재 (사례수 > 0)
4. 실패한 사례만 리포트
5. 결과를 data/test_results/full_type_test.json에 저장
```
