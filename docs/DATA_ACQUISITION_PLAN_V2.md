## 실행 순서

### Step 1: 유사사례 자동 수집 (D-1)

**목표**: 가짜 50건을 실제 EIASS API 데이터로 교체

**Claude Code 프롬프트**:
```
docs/DATA_ACQUISITION_PLAN_V2.md를 읽고 Step 1을 실행해줘.
```

**상세 작업 내용**:

backend/scripts/collect_cases.py 생성:

1. 환경영향평가 정보 서비스 API 호출 (API #13)
   - URL: https://apis.data.go.kr/1480523/EiaInfoService
   - 사업유형별 검색 (도로, 산업단지, 발전소, 주거, 관광, 하천, 폐기물, 항만, 군사)
   - 2018~2025년 완료 사업
   - 수집: 사업명, 사업유형, 위치, 연도, 평가구분

2. 협의 현황정보 서비스 API 호출 (API #14)
   - URL: https://apis.data.go.kr/1480523/EiaConsltService
   - 수집된 사업별 협의 결과 조회
   - 수집: 동의/조건부동의/보완후재협의/부동의

3. 결정내용정보 서비스 API 호출 (API #15)
   - URL: https://apis.data.go.kr/1480523/EiaDecsnService
   - 주요 지적사항, 보완 요구사항 추출

4. 수집된 원본 데이터를 data/cases/raw/에 JSON으로 저장

5. Gemini API로 태깅 보조:
   - 원본 텍스트 → 태깅 스키마에 맞게 구조화
   - key_issues, remediation_required, public_concerns, tags 자동 생성
   - summary, lessons_learned 자동 생성

6. 최종 결과를 data/cases/cases.json에 저장 (기존 가짜 50건 교체)

7. 사업유형별 목표 건수:
   - 도로/교통 12건, 산업단지/공장 8건, 발전소/에너지 7건
   - 주거/택지개발 6건, 관광/레저 5건, 하천/수자원 4건
   - 폐기물/환경 3건, 항만/공항 3건, 군사시설 2건

8. 실행: python backend/scripts/collect_cases.py
   - .env에서 DATA_GO_KR_API_KEY와 GEMINI_API_KEY 사용
   - API 호출 간 1초 딜레이 (rate limit 대응)
   - 진행 상황 로그 출력

9. 수집 완료 후 case_search.py 테스트 실행

data/regulations/ 3개 JSON 확장:

1. zone_code_mapping.json (21개 → 80개+)
   - 국토의 계획 및 이용에 관한 법률 제36~42조 기준
   - 용도지역 4대 분류 → 세부 17종 (주거 7, 상업 4, 공업 3, 녹지 3)
   - 용도지구 15종+ (경관, 고도, 방화, 방재, 보호, 취락 등)
   - 용도구역 8종+ (개발제한, 도시자연공원, 시가화조정 등)
   - 각 항목: zone_code, zone_name, category, legal_basis, building_coverage_ratio, floor_area_ratio, restriction_summary, eia_sensitivity, eia_notes, common_issues

2. conservation_type_mapping.json (21개 → 60개+)
   - 자연환경보전법: 생태경관보전지역 3종
   - 자연공원법: 국립/도립/군립/지질공원 + 용도지구 12종
   - 야생생물보호법: 보호구역 3종
   - 습지보전법: 3종
   - 수도법, 하천법, 산지관리법, 산림보호법, 문화재보호법, 해양생태계법, 백두대간보호법
   - 각 항목: conservation_code, conservation_name, legal_basis, managing_agency, restriction_level, restrictions, buffer_required_m, eia_severity_default, eia_notes, permit_required, permit_agency

3. eia_thresholds.json (14개 → 30개+)
   - 환경영향평가법 시행령 별표3 기준 전체 대상사업
   - 도시개발, 산업입지, 에너지, 항만, 도로, 수자원, 철도, 공항, 하천, 관광, 산지, 체육, 폐기물, 국방 등
   - 각 항목: project_type, sub_type, threshold, unit, legal_basis, required_items
