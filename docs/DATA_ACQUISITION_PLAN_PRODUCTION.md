## Claude Code 실행 프롬프트

### Step 1: Tier 1 데이터 추가 (문화재 + 수리수문 + 상수원 + 법령)

```
다음 4개 신규 커넥터를 추가해줘. 기존 커넥터 패턴(backend/app/connectors/)을 따를 것.

## 커넥터 1: 문화재 보호구역 (heritage)
- API: 국가유산청 문화재 공간정보 WFS
- URL: https://gis-heritage.go.kr/checkKey.do
- 기능: 좌표 반경 내 지정문화재 + 보호구역 조회
- 정규화 필드: heritage_name, heritage_type, protection_zone, distance_m, designation_date
- 규칙 추가: 
  - HER-001 Critical: 문화재 보호구역 직접 중첩 (현상변경 금지)
  - HER-002 Major: 역사문화환경 보존지역 중첩 (500m 이내)
  - HER-003 Review: 매장문화재 유존지역 인접
- 규제 매핑: 문화재보호법 제35조, 제13조

## 커넥터 2: 수리·수문 (hydrology)
- API: WAMIS 국가수자원관리 (wamis.go.kr)
- 기능: 좌표 인근 하천수위, 유량, 홍수위 조회
- 정규화 필드: station_name, water_level, flow_rate, flood_level, river_name
- 규칙 추가:
  - HYD-001 Major: 홍수위 이하 저지대 (침수 위험)
  - HYD-002 Review: 하천 유지유량 부족 구간
- 초안 섹션 B-2 수리·수문에 자동 반영

## 커넥터 3: 상수원보호구역 (water_protection)
- API: 환경공간정보 WMS (기존 ecology 커넥터의 WMS 엔드포인트 확장)
- 기능: 상수원보호구역 + 수변구역 + 특별대책지역 조회
- 정규화 필드: zone_type, zone_name, distance_m
- 규칙 추가:
  - WPR-001 Critical: 상수원보호구역 직접 중첩
  - WPR-002 Major: 수변구역 중첩 (500m)
- 규제 매핑: 수도법 제7조, 4대강법 제4조

## 커넥터 4: 법령 개정 감지 (law_monitor)
- API: 법제처 국가법령정보 Open API (open.law.go.kr)
- 기능: 관련 법령 6개의 최종 개정일 조회
- 대상 법령: 환경영향평가법, 자연환경보전법, 국토계획법, 농지법, 습지보전법, 하천법
- 구현: 
  - backend/app/services/law_monitor.py
  - 시작 시 법령 버전 체크 → data/law_versions.json에 저장
  - 개정 감지 시 관리자 알림 (프론트엔드 배너)
  - GET /api/law/status → 법령 최신성 상태 반환

추가로:
- marine 커넥터 데이터를 draft_copilot.py 3.해양환경 섹션에 연동
- greenhouse 커넥터 데이터를 draft_copilot.py 3.온실가스 섹션에 연동 (energy 유형 한정)
- data/rules/에 새 규칙 YAML 추가
- data/regulations/에 새 규제 매핑 추가
- 프론트엔드 데이터현황 페이지에 새 커넥터 4개 표시

pytest + pnpm build 확인.
```
